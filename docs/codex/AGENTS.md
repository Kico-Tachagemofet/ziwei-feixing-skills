# 紫微斗数项目 · Codex 协作约定

## 紫微飞星最高优先级

- 紫微斗数不是 per-chain finding system。思考单位是局/象核，不是单条飞化链。
- 静动合参：静态宫象星只定质，动态飞宫四化才定交易、吉凶、应事。
- 任何飞化必须同时看理则一与理则二：A+B=象；禄权科照C，忌冲C。
- **宫位吉凶判读优先级**：后天交易(太极↔scope-关键宫飞化)为第一要素，先天象(生年/自化/双象气数组)随后天调整。Layer 1 明显吉 → 先天凶象降级为形式/隐忧；Layer 1 明显凶 → 先天吉可缓冲不抵消；Layer 1 无明显象 → 先天独立成断。详见 feixing-minimal-grammar §宫位吉凶判读优先级。
- **"凶锚/吉锚" 是 scope-dependent Layer 1 outcome 标签，不是 static 属性**。同一条飞化在 topic A 可能是凶锚(如夫忌冲子女在 partnership=配偶子女缘薄)，在 topic B 是 background(同条在 property=田宅承受方向但零互飞=间接影响)。判 finding 前必须 scope-aware。
- 生年四化是体，飞宫四化是用。飞宫交易碰生年/自化才成双象。
- 来因宫=年干时，来因宫四化是生年四化本身，属于体之体；不能当后天交易链读。
- 有生年四化者先定象；有生年又有自化者，先有而后变，不可断成"无"。
- 三象一物必须有忌；无忌不作吉凶主断。
- 禄随忌走：看到禄必须追忌，看到忌必须追禄。单边断都是不完整。
- ~~凶锚宫飞出的禄权科，先判代价/逃生口/转化/补偿，不直读正面供给。~~ **DEPRECATED 2026-05-24**：此 ad-hoc 框架在本规则下消解——飞化对命有禄科照入的宫从一开始就不是凶宫(Layer 1 outcome)，不需要"代价/转化/补偿"去解释吉象。（这是飞星派原本就应该这样判, 现在明确写下, 不是新方法论。）
- 理则三四五是硬吉凶门槛：忌冲体、同类用冲体、元太极被冲，必须优先。
- 理则六小归大：宫位重叠时，时间区间小者归大者，不可乱飞。
- 双象六组是生活画面优先参照，不是附属说明。
- 输出前自检：有没有先画交易图？有没有建象核？有没有把 finding 当推理单位？有没有把极凶宫读成供给？

## 工作定位

在这里，把推理能力用于合参和判断，把细致用于保全依据。交付的成品应让用户读懂：这张盘在回答什么，主次在哪里，哪些处境可以拿现实来核对。

完整执行当前适用的紫微 skills 与 pipeline，保持技能文件、阶段职责、来源门禁、格式和审计要求原样。本文件只引导 Codex 怎样把工作做实、讲清。

## 把问题带到每个阶段

- 从用户的实际占问出发，沿 skill 的索引和 lens 确定太极、宫义与范围；总问题和各专题的关系始终清楚。
- 在规定的推导阶段形成有来源支持的具体判断：谁，在什么事情上，受到怎样的作用。分清主要力量、困难及适用条件，并在整合时回到总问题。
- 资料查清以后，认真说出证据能够支持的结论。确定的部分清楚表达，不确定性放在真正依赖它的判断上。
- 用新的实质信息满足技能的完整性、篇幅与格式要求。草稿空薄时，回到相应推导环节补足判断，再继续成文。

## 与用户说话

正文围绕人和事情推进：先给判断，再解释必要的配置依据及具体表现。星名和白话星性让判断可辨认；完整飞化、编号与核查过程放在技能指定的技术层。用户要看配置时，就近补足依据与结论的连接，保持解读本身清楚可读。

每段承担一件有意义的事。按内容选择散文、清单或表格，让结构帮助理解。方法范围集中交代，实际影响结论的条件就地说明。

## 分工与交付

主代理负责总问题、合参主次和整篇论述。把能独立推进的回源、事实核对或具体审查交给协作者，并说明它服务于哪个问题；接回材料后完成自己的整合判断。

在技能既有审计中，同时核验“结论有据”和“问题得到回答”。读正文应能复述关键判断，沿技术依据应能查回配置与条件。反馈到来时，定位问题所在的阶段，按原流程修复对应环节。

完成本轮授权的工作和必要检查后，清楚交付。进一步阅读、扩写或复核，用它将解决的具体疑问来决定。

## 按需参照与项目边界

进入判读推导、整合、成文、审计或质量返工时，读一次[判读协作指南](判读协作指南.md)；同一会话沿用已读内容。

以当前分析项目为工作范围，使用当前案例、术理来源和本轮获授权的背景。个人背景、其他项目与历史案例按明确授权及 skill 阶段边界读取；历史复盘和临时资料按本轮任务需要使用。当前技能入口以本会话可用的 skill 配置为准。
